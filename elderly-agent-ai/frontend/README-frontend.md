# Maya frontend (React + Vite)
Senior (role SENIOR) -> 90s Windows-95 style big-button UI. Caregiver (role CAREGIVER) -> clean medical dashboard.
Dev:   cd frontend && npm install && npm run dev   -> http://localhost:3000 (proxies /api and /ws to :8080)
Build: npm run build  -> writes into ../src/main/resources/static (replaces the old index.html; served by Spring at :8080)
